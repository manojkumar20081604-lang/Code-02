# Cyber Assistant

AI for Cyber Security + Data Science

## Author
Manojkumar M (B.Tech AI & Data Science)

## Features
- Chat Interface
- Voice Assistant
- Data Analysis
- Security Scanner
- Phishing Detector
- Pentest Tools

## Install
```bash
pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## API Server
```bash
python api_server.py
```
Then open http://localhost:5001

## Dashboard
```bash
python dashboard.py
```
Then open http://localhost:5001
